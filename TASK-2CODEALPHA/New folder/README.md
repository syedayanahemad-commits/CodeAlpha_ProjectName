# Stock Trading Platform

## Overview

Stock Trading Platform is a Java-based simulation project developed during the CodeAlpha Java Programming Internship. It allows users to simulate stock market trading operations and track portfolio performance.

## Features

* Simulated stock market environment
* Buy stock functionality
* Sell stock functionality
* Portfolio management
* Track investment performance
* Transaction handling
* Object-Oriented design

## Technologies Used

* Java
* OOP Concepts
* Collections Framework
* File Handling

## How to Run

1. Compile:

   ```
   javac --module-path "C:\Users\hp\Desktop\MYSYSTEM\JavaFX\javafx-sdk-26.0.1\lib" --add-modules javafx.controls *.java
   ```
2. Execute:

   ```
   java --module-path "C:\Users\hp\Desktop\MYSYSTEM\JavaFX\javafx-sdk-26.0.1\lib" --add-modules javafx.controls Main

   ```
