# Student Grade Tracker

## Overview

Student Grade Tracker is a Java application developed as part of the CodeAlpha Java Programming Internship. The system helps manage student grades, calculate statistics, and generate performance reports.

## Features

* Add and manage student records
* Store grades using ArrayList
* Calculate average marks
* Find highest score
* Find lowest score
* Display summary report
* User-friendly interface

## Technologies Used

* Java
* OOP Concepts
* ArrayList Collections
* Java Swing / Console

## How to Run

1. Compile the project:

   ```
   javac *.java
   ```
2. Run:

   ```
   java StudentGradeTrackerGUI
   ```

## Learning Outcomes

* Data management using collections
* Object-Oriented Programming
* Basic report generation
* Java application development
