# Artificial Intelligence Chatbot

## Overview

Artificial Intelligence Chatbot is a Java-based conversational assistant developed during the CodeAlpha Java Programming Internship. The chatbot provides interactive communication through a modern graphical user interface and AI-powered responses.

## Features

* Interactive chatbot interface
* Modern GUI design
* Real-time conversation
* AI response generation
* API integration
* Chat bubbles interface
* Smooth user experience
* Responsive layout

## Technologies Used

* Java
* Java Swing
* HTTP Client API
* JSON Processing
* Jackson Library
* Gemini API
* OOP Concepts

## How to Run

1. Add required libraries:

   * Jackson Core
   * Jackson Databind
   * Jackson Annotations

2. Compile:

   ```
  javac -cp ".;..\libs/*" -d ..\out *.java
   ```

3. Run:

   ```
   java -cp ".;..\out;..\libs/*" ModernChatbotGUIV2
   ```
