# Hotel Reservation System

## Overview

Hotel Reservation System is a Java-based booking platform developed during the CodeAlpha Java Programming Internship. The system allows users to browse hotels, book rooms, simulate payments, and manage reservations.

## Features

* Hotel listing interface
* Room categorization

  * Standard
  * Deluxe
  * Suite
  * Luxury
* Hotel search functionality
* Booking management
* Reservation handling
* Payment simulation
* Booking details generation
* File I/O storage
* Modern GUI interface
* Hotel image integration

## Technologies Used

* Java
* Java Swing
* OOP Concepts
* File Handling
* Collections Framework

## How to Run

1. Compile:

   ```
   javac *.java
   ```

2. Run:

   ```
   java Main
   ```

## Learning Outcomes

* GUI application development
* Booking system implementation
* File-based data storage
* Event handling
* Object-Oriented Design
